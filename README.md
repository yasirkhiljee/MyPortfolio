# Yasir Khan — Portfolio

Personal portfolio site for Yasir Khan, Senior Android & React Native Engineer. Built with React, Vite, Tailwind CSS, and Framer Motion.

## Stack

- React 19 + React Router
- Vite 8
- Tailwind CSS 4
- Framer Motion
- React Icons

## Development

```bash
npm install
npm run dev      # start dev server
npm run build     # production build
npm run preview   # preview production build locally
npm run lint       # run ESLint
```

## Structure

- `src/sections` — page sections rendered on the home route
- `src/components` — shared, reusable UI pieces
- `src/data/portfolioData.js` — content for hero, about, skills, projects, blog, and contact
- `src/hooks` — small reusable hooks (reduced motion, active-section scroll spy, document meta)
